## 4. 시각 스타일

포스터와 캐릭터 PNG에서 추출한 색을 그대로 쓴다.

| 토큰 | 값 | 용도 |
|---|---|---|
| `--cream` | `#F8F0DA` | 페이지 배경, 테라코타 위 글자 |
| `--terracotta` | `#C0603C` | 제목, 배지, 쿠폰 카드 배경, 버튼 |
| `--crust` | `#A54B36` | 캐릭터 빵 껍질색, 강조·hover |
| `--ink` | `#6E3A28` | 작은 본문 글자 (크림 배경 대비 8.03:1) |
| `--paper` | `#FCF7EA` | 카드 배경 |

- **대비 규칙 (실측):** 테라코타 `#C0603C` ↔ 크림 3.71:1 → **큰 글자(24px 이상, 또는 18.66px 이상 굵게)와 장식에만** 쓴다. `--crust` `#A54B36` ↔ 크림 5.05:1 → 작은 강조 글자, 크림 글자를 올리는 버튼·배지 배경. 작은 본문은 `--ink`. 쿠폰 카드처럼 테라코타 배경에 크림 글자를 올릴 땐 24px 이상 또는 18.66px 이상 굵게.
- **폰트** (Google Fonts):
  - 제목·숫자: **Jua**. 포스터의 "점심할인", "3,000원"처럼 둥글고 두꺼운 느낌
  - 손글씨 포인트(부제, 조건 체크 목록, 영문 소제목): **Gaegu**
  - 작은 정보 글자(주소, 영업시간): 시스템 고딕 (`-apple-system, "Apple SD Gothic Neo", "Malgun Gothic", sans-serif`)
  - 구현 중 포스터 옆에 놓고 비교해 더 가까운 폰트가 있으면 교체할 수 있다.
- **모티프:** 점선 타임라인, 둥근 모서리 카드(큰 radius), 티켓 반원 홈, 달력 아이콘, 네 잎 꽃 장식, ♥, 알약 모양 태그
- 다크 모드 없음 (`color-scheme: light`, 브랜드 톤 유지)
- 애니메이션은 최소한으로. 섹션이 나타날 때 살짝 떠오르는 정도, `prefers-reduced-motion`이면 끈다.

## 6. 시간 기반 표시 (js/main.js)

### 공통
- 기준 시각은 **항상 한국 시간** (`Intl.DateTimeFormat`의 `timeZone: 'Asia/Seoul'`). 해외에서 열어도 매장 기준으로 표시된다.
- 1분마다 다시 계산한다.
- 시간 데이터는 JS에 하드코딩하지 않고 HTML의 `data-*` 속성에서 읽는다. 예: `<li data-start="09:30">`. 빵 시간이 바뀌면 HTML만 고치면 된다.
- JS가 꺼져 있거나 실패해도 모든 정보는 그대로 보인다 (배지만 안 뜸).
- 테스트용: URL에 `?now=2026-09-01T11:30`을 붙이면 그 시각(한국 시간)으로 계산한다.

### 영업 상태 배지 (첫 화면)
| 조건 (한국 시간) | 표시 |
|---|---|
| 08:00 ≤ 지금 < 21:00 | 🟢 지금 영업 중 · 21시까지 |
| 지금 < 08:00 | 오늘 아침 8시에 문 열어요 |
| 지금 ≥ 21:00 | 오늘 영업 끝 · 내일 아침 8시에 만나요 |

### 빵 시간 강조 (타임라인)
각 행은 `data-start`와 선택 속성 `data-end`를 가진다 (8:00 행만 `data-end="09:00"`, 나머지는 end = start).
- **지금 나오는 중:** start ≤ 지금 < end 인 행
- **방금 나왔어요:** end ≤ 지금 < end + 30분 인 행 중 가장 최근 것 하나
- **다음 빵:** start > 지금 인 행 중 가장 가까운 것 하나에 배지 + 강조 스타일
- 08:00 이전: 8:00 행에 "첫 빵 8시" 배지만 표시
- 11:30 ~ 21:00: 행 강조 없음. 타임라인 위에 "오늘 빵이 모두 나왔어요" 한 줄
- 21:00 이후: 아무것도 표시하지 않음

예) 09:35 → 9:30 행 "방금 나왔어요", 9:40 행 "다음 빵"

### 오늘의 혜택 배지 (할인 카드)
| 조건 | 쿠폰 카드 | 점심할인 카드 |
|---|---|---|
| 1~3일 | "오늘은 쿠폰 받는 날!" | 배지 없음 |
| 1~3일이 아니고 11:00 ≤ 지금 < 13:00 | – | "지금 할인 중!" |
| 그 외 | – | – |

영업시간 밖에서는 두 카드 모두 배지를 띄우지 않는다.

### 주소 복사
`navigator.clipboard.writeText`를 쓰고, 실패하면 주소 텍스트를 선택 상태로 만들어 직접 복사하게 한다.

## 9. 미정 사항 (구현을 막지 않음)

- **호스팅:** 어디에 올릴지(GitHub Pages, Netlify 등) 정해지면 og:image 절대 주소와 canonical URL을 채운다. og:image는 절대 주소여야 미리보기가 뜨므로, 호스팅 전까지는 카카오톡 링크 미리보기에 사진이 안 나온다 (title·description은 나옴).
- **네이버 플레이스 링크:** 가게 네이버 플레이스 주소를 받으면 `네이버 지도` 버튼을 검색 링크 대신 플레이스 링크로 바꾼다.
